# ゲーム環境なしでの面情報取込

[demo-surface-info.ini](demo-surface-info.ini) は架空のブロックの面情報です。ゲーム内アセットは含みません。

1. INI ファイルを Windows 側へ保存します。
2. アプリの「面情報取込」→「開く」で、この INI ファイルを選択します。
3. 取込ダイアログの「適用」を押します。プロジェクト用のヘッダーの「開く」ではなく、面情報取込ダイアログ内の「開く」を使ってください。
4. 左側で正方形の面（512×512）と横長の面（512×256）を切り替え、図形や文字を追加して編集できます。

両面の TextureSize は512×512です。横長の面は中心を共有する可視領域が512×256であり、上下の余白は可視領域外です。

BlockId は動作確認用の仮IDです。Owner には使わないでください。このサンプルではゲーム側の実表示や接続は検証できません。
